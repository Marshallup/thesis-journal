# ADR-0002. UI-стек: Base UI + shadcn CLI, внешний вид свой

**Дата:** 2026-09-10
**Статус:** принято

## Контекст

Нужен фронтенд, который не выглядит сгенерированным, но не съедает недели, отведённые на бэкенд. Проект учебный: фронт должен показывать инженерную зрелость, а не количество установленных пакетов.

Состояние экосистемы на сентябрь 2026:

- Base UI (команда MUI) достиг 1.0 в декабре 2025, сейчас `@base-ui/react` 1.8 — пакет переименован из `@base-ui-components/react`. Поддерживается фултайм-командой.
- Radix куплен WorkOS, скорость обновлений сложных компонентов упала.
- shadcn/ui с июля 2026 ставит Base UI по умолчанию: когда дали выбор, пользователи выбирали его вдвое чаще Radix.
- shadcn CLI v4 (март 2026) превратился в инфраструктуру: пресеты, реестры, `shadcn docs`, MCP-сервер и skills для кодовых агентов.

## Решение

**Base UI** — слой поведения. **shadcn CLI v4** — способ доставки кода в репозиторий. **Внешний вид — собственный**: токены, типографика, плотность пишутся с нуля, дефолтная тема shadcn не используется.

Пресеты shadcn не применяем: пресет приносит чужую тему.

Компонент, установленный из реестра, приводится к нашим токенам в той же задаче.

## Отвергнутые варианты

**Mantine 9 / HeroUI 3 / Chakra 3.** Быстрее всего по времени до первого экрана, но покупается чужая эстетика, и потом с ней борешься. Перекрасить готовую библиотеку в свою систему дороже, чем собрать свою на примитивах. Отдельно: «взял Mantine» не даёт истории для собеседования.

**React Aria Components.** Лучшая доступность в экосистеме, но заметно многословнее и менее узнаваем на рынке. Оставлен как запасной вариант, если доступность станет отдельной целью.

**Ark UI + Panda CSS.** Технически самый стройный вариант — рецепты и типобезопасные токены. Отклонён по срокам: ещё один билд-слой и своя ментальная модель на девятинедельном проекте.

**Коммерческий кит (Tailwind Plus, Untitled UI).** Гарантированный вкус за деньги, но так же узнаваем, как дефолтный shadcn.

**Чистый Base UI без shadcn CLI.** Практически то же самое, что принято, только медленнее стартует и без skills, которые дают агенту актуальный API.

## Последствия

- Первые два-три компонента будут медленными: сначала пишется слой токенов. Дальше быстро.
- Решения по палитре и типографике приняты явно и записаны в `docs/ui-system.md` — их можно оспорить, но не проигнорировать.
- Появляется риск, которого нет у готовой библиотеки: при небрежности система расползётся. Противоядие — короткий список своих компонентов и запрет на вторую библиотеку.
- Оценка недели 2 выросла примерно на день (слой токенов и `Money`).
