# Фронтенд

Полное описание — `docs/ui-system.md`. Здесь только то, что нарушается чаще всего.

## Внешний вид

- **Токены только свои.** Дефолтную палитру shadcn/Tailwind (`zinc`, `slate` как основа) не использовать: она узнаётся с одного взгляда и делает продукт неотличимым от сгенерированного.
- Шрифты: `Source Serif 4` для человеческого текста (тезис, заметка), `IBM Plex Sans` для интерфейса и чисел. Inter не подключать.
- **Карточек нет.** Основная структура — регистр: плотные строки, тонкие линейки, числа по правому краю. Не заворачивать содержимое в плитки с тенями.
- Прибыль и убыток — бирюза `#0F766E` и слива `#8B2C55`, не светофорные зелёный с красным. Знак и направление читаются без цвета: цвет — вторая подсказка, не первая.
- Не использовать: ALL-CAPS-надзаголовки, стрелку `→` в тексте кнопок, «А · Б · В» через средние точки, одинаковый радиус на всём подряд, градиенты как украшение.

## Компоненты

- Примитивы — Base UI (`@base-ui/react`). Ставить через `pnpm dlx shadcn add`, дальше это наш код.
- После установки компонента из реестра **сразу** привести его к нашим токенам: дефолтные классы не оставлять «на потом».
- Своих компонентов мало и они простые: `Money`, `Stat`, `Table`, `Field`, `Sheet`. Всё остальное — из реестра или Base UI.
- Не тащить вторую библиотеку компонентов. Одна конкурирующая система — и внешний вид рассыпается.

## Числа и деньги

- Деньги приходят с бэкенда строками и остаются строками. `parseFloat` над деньгами — ошибка.
- Форматирование — `Intl.NumberFormat` с `useGrouping` и табличными цифрами (`font-variant-numeric: tabular-nums`), чтобы колонки не прыгали.
- Живые значения (стоимость портфеля) — через `@number-flow/react`. Это единственная анимация, запускаемая не пользователем.

## Данные

- Запросы — TanStack Query. Ручной `useEffect` + `fetch` не писать.
- Таблицы — `@tanstack/react-table` + виртуализация при списках длиннее 200 строк.
- Графики: `lightweight-charts` для цен и свечей, `ECharts` или собственные SVG для срезов. `Recharts` не использовать.

## Доступность

- Видимый фокус на всех интерактивных элементах, `prefers-reduced-motion` уважается, контраст текста не ниже 4.5:1.
- Цвет никогда не единственный носитель смысла.
